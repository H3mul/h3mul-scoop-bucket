# h3mul-scoop-bucket

A custom Scoop bucket for several unpackaged projects

## Installation

Add this bucket to your Scoop installation:

```powershell
scoop bucket add h3mul https://github.com/h3mul/h3mul-scoop-bucket
```

## Requirements

- Windows 10 or later
- Scoop package manager
